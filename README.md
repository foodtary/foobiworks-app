# 푸비웍스 데스크톱 앱 — 다운로드

푸드의비서 사내 포털 **푸비웍스** 데스크톱 앱 설치파일을 받는 곳입니다.

## 다운로드
**[최신 버전 받기 →](https://github.com/foodtary/foobiworks-app/releases/latest)**

페이지 아래쪽 **Assets**에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| 윈도우 | `Foobiworks-버전-win-x64.exe` |
| 맥 (M1 이후, 2021년 이후 대부분) | `Foobiworks-mac-AppleSilicon.zip` |
| 맥 (인텔) | `Foobiworks-mac-Intel.zip` |

## 설치할 때
- **윈도우:** "PC 보호" 창이 뜨면 **추가 정보 → 실행**
- **맥:** zip을 풀고 '응용 프로그램' 폴더로 옮긴 뒤 실행. 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**

설치 후에는 앱이 알아서 최신 버전으로 업데이트합니다.
